# Dataset Information

## Dataset Used
Indian Railway Train Details dataset.

Original filename: `Train_details_22122017.csv`

## Purpose
The dataset contains train and station route information used for railway data cleaning, exploratory data analysis, and Power BI visualizations.

## Data Processing
The project uses Python and Pandas to clean and validate the data before preparing the processed CSV file for Power BI.
