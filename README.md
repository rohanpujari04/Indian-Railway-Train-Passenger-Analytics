# Indian Railway Train & Passenger Analytics

## Project Overview
This project analyzes Indian Railway train route and station data using Python, Pandas, NumPy, and Power BI. It explores train routes, station information, route distances, and train halt times to generate useful insights through data analysis and visualization.

## Objectives
- Analyze Indian Railway train and station records.
- Clean and validate the dataset using Python.
- Explore route distances and station-level information.
- Visualize railway data through an interactive Power BI dashboard.
- Present key insights using charts, KPI cards, and slicers.

## Tools & Technologies
- Python
- Pandas and NumPy
- Data Cleaning and Exploratory Data Analysis (EDA)
- Power BI
- CSV Dataset

## Project Dashboard
The Power BI report contains two pages:
- **Railway Analytics Dashboard**
- **Detailed Analysis**

The report includes KPI cards, charts, and interactive slicers to explore the data.

## Dataset
The project uses Indian Railway train and station route data. The original dataset source and attribution will be added to this repository.

## Project Files
- `analysis.py` — Python analysis and data processing.
- `Indian_Railway_Analytics.pbix` — Power BI report.
- `Indian_Railway_PowerBI_Data.csv` — Processed data for Power BI.

## How to Use
1. Download or clone this repository.
2. Open `analysis.py` to review the Python analysis.
3. Open `Indian_Railway_Analytics.pbix` using Microsoft Power BI Desktop.
4. Use the dashboard slicers and charts to explore the available data.
